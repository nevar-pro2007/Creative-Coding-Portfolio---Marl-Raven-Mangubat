# Experiment 1: The VariaLoop Art

## [Live Version](https://nevar-pro2007.github.io/Creative-Coding-Portfolio---Marl-Raven-Mangubat/Experiment_1-The_VariaLoop_Artwork/)

## Documentation

**Inspiration and Starting Point:**
In this first experiment, the inspiration for this was the in-class demo when the creative coding class started. The starting point for this sketch was a combination of foundational p5.js drawing principles and the minimalist aesthetic of Bauhaus design, which focuses on geometric purity and structural balance. While the core tasks were derived from the project requirements, the visual inspiration came from exploring how simple repeating units can create complex textures, similar to the "Form and Color" exercises pioneered by artists like Wassily Kandinsky.

**Code Techniques and Development Process:**
The development process of this experiment began by establishing a global variable system to control the shapes. By using variables like shapeSize function and mainCol function to ensure that the primary visual elements remained flexible and easily adjustable. Then, I have also implemented a nested for loop to generate a background grid. While experimenting with this artwork, I found that a standard grid felt too rigid. To resolve this issue, I started calculating specific offsets by using math within the loop to create even spacing that did not feel cluttered. I have also experimented with different stroke weights and color transparency. My first attempt at this work was too simple. To resolve this, I have mixed variables and loops together to create an attractive look. I have lowered the stroke weight and using a muted gray, which allowed the shapes to pop against the background. I have also added text to my work so it could be more attractive.

**Self-Reflection:**
The most successful part of this sketch is the integration of Task 1 and Task 2 mixed together into a cohesive mosaic style. The use of the random function to change the primary color upon every refresh fulfills the extension requirement while adding a generative feel to the work. If I were to work with it again and improve the code, I would definitely look into adding more variety within the loop perhaps using a conditional if statement to randomly decide whether to draw a line or a rectangle at each grid point. This would move the project further into the world of generative art by adding more unpredictability to the controlled structure. Overall, the sketch demonstrates a clear understanding of how variables drive visual output and how loops create rhythm.
