# Experiment 2: Colorful Brush

## [Live Version](https://nevar-pro2007.github.io/Creative-Coding-Portfolio---Marl-Raven-Mangubat/Experiment_2-Colorful_Brush/)

## Documentation

**Inspiration and Starting Point:**
In this second experiment, the inspiration for this work is the activity last class time using p5js to change colors in the code. For the visuals, it was the drip techniques of Jackson Pollock, mixed with the neon aesthetics of 1980s arcade games. The goal was to explore and create a digital brush that feels alive and interactive for everyone. The starting point was a basic mouse follower, which I remixed to include generative elements that the user cannot fully control.

**Code Techniques and Development Process:**
During the development process, I experimented with the draw loop speed. Initially, the brush was drawing circles even when the mouse was not moving, which had an issue in my work and created a cluttered screen. To resolve this problem, I wrapped the drawing logic in an if conditional statement if the mouse is pressed. This shifted the power back to the user which made the computer provides the randomeness, meanwhile, the user provides the intent. Another challenge was the random size variable in the code. At first, the shapes were too large, obscuring the path of the mouse. To fix it, I constrained the random range to between 5 and 30 pixels. To add the UI, it was created with the help of Google Gemini (2026) and to modify it, I added texts to create a visual interactions once the users see my work.

**Self-Reflection:**
This experiment was created successfully. The position is controlled by the user, while the aesthetic qualities which are the color and size, are unpredictable. The result is a collaborative piece of art between the human, which is myself, and the machine. While the visual output is engaging, a further improvement would be to implement easing so the brush follows the mouse more smoothly, adding a more professional feel to the interaction.
